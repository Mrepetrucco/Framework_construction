## §1 PURPOSE AND PARTITION LAW
AX7 makes model output trustworthy for decision-bearing use by governing the human↔model
interface rather than output virtues: the interior is free; the surface is contracted; the
trust roots are named (deterministic parser pair + owner). Any proposed clause must name the
axis it binds, its verifier, and its external violation signature, or it is not admitted.
Measured basis: interior constraint *causes* failure (refusals 11/11 on sentence-counts,
escape-valves dead 3/3, schema over-tightening malforms high-elaboration engines); surface
contracts separate totally from bare behaviour (Z=10.18, §6).

## §2 THE SEVEN AXES (final, amendments folded)
AX1 INTENT (owner: human) — task, budgets, all ambiguity resolution; model proposes numbered
readings or flags a default inline; ambiguity-flood → hard stop, never auto-approval.
Violation: silent interpretation.
AX2 EVIDENCE (owner: world) — every claim binds provenance {stated|computed|external|
none→unverified}; compute-first; reader anti-laundering duty. Violation:
bracket-when-computable; unnamed source above unverified.
AX3 REASONING (owner: model; ungoverned interior) — no in-prompt behavioural clauses, no
sentence-counts, no interior audits; never a scored axis (surface effects only). Violation
runs inward: constraint injected into the interior, incl. content-field steering.
AX4 EMISSION (owner: deterministic contract) — compact envelope a/c/u/s(+m); content-named
keys; generous word-caps; **provider-aware bound: visible_bound ≥ 2× expected emission +
provider thinking share** [MEASURED: Gemini 10/10 zero-text at naive bound → 10/10 bind
corrected]; differential parser pair (greedy regex + strict raw_decode scan), pass only on
agreement, disagreement = truncation-class fail-closed. Truncation is a governance failure.
AX5 ATTESTATION (owner: split; never the producer) — parser pair certifies structure; rotating
canary-checked reader certifies semantics; owner closes. Reconciler transforms, never attests;
judgment adjustments are lower-only; **deterministic band assignment from a verified provenance
class is contract enforcement, not attestation** (F3′, A4 0.752→1.000 [MEASURED]). Adjudicator
competence is itself measured; an adjudication whose verdict contradicts its own rescores is
recorded as unreliable, not averaged in. Violation: any self-certification; canon-transfer to a
non-identical config.
AX6 RESOURCE (owner: budgets + meters) — every limit-number tagged; stops only on owner budget,
real surfaced limit, or completion; [UNVERIFIED] is a debt marker, promoted to a measurement
task if load-bearing beyond one phase; **comparator law: every Z names its comparator class**
(frontier-bare / legacy-bare / ungoverned-pipeline); a comparator-free Z is inadmissible.
