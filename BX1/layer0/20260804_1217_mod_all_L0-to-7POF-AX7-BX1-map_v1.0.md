L0 (owner prose) is the ONLY ground truth. 7POF, AX7 and BX1 are THREE PROJECTIONS OF THE SAME L0 CORPUS at
different encoding sites — not three generations of one lineage, and not layers of each other.

    L0 owner utterances

      |           Suitably-granular · Deep-learning · Calibration)         [encoding site: prose]
      |-- AX7   : projection onto INTERFACE AXES   (AX1 Intent · AX2 Evidence · AX3 Reasoning · AX4 Emission ·
      |           AX5 Attestation · AX6 Resource · AX7 Failure)            [encoding site: prose]
      +-- BX1   : projection onto RUNNER MECHANISM (X0-X9 across A/M/R/I/P) [encoding site: executable machinery]

## THE DEFECT THIS EXPOSES
AX7 was derived FROM 7POF ("the interface reorganisation OF the seven principles"), and BX1 was derived from the
measured behaviour OF that pair. That is CHAIN topology: each layer validated against the layer above, not
against the owner's words. Under chain topology fidelity decays multiplicatively and the decay is unverifiable,
because every check references the layer above rather than the source.
=> REQUIRED CORRECTION: 7POF, AX7 and BX1 each re-point to L0 ids DIRECTLY. AX7 must not be justified by "it
reorganises 7POF"; it must be justified by the L0 utterances it serves. Same for BX1.

## WHAT EACH PROJECTION IS GOOD FOR (they are not redundant)
- 7POF answers "what must the OUTPUT be like" — the owner-facing quality vocabulary. Stays prose because the
  owner's channel is prose (L0-D15).
- AX7 answers "where in the human<->model INTERFACE does each obligation act" — the routing vocabulary.
- BX1 answers "what mechanism ENFORCES it and what remains merely measured" — the only projection that can carry
  a guarantee, and the only one that must never be read rather than executed.
- A single L0 id typically projects into all three. Example: L0-D7 (raise, do not probe) -> 7POF High-fidelity /
  Calibration · AX7 AX1 Intent + AX7 Failure · BX1 uncertainty-raise rule + X2R correlation raise.

## BX1's SEPARATE-GENERATION STATUS (L0-D17) IS PRESERVED
BX1 is NOT a successor edition of 7POF/AX7 in a version line; it is a different ENCODING SITE for the same
corpus. That is exactly what "separate generation ... but directly informed by 7POF and AX7 (directly evidential
as well as their construction history)" licenses: shared ground truth, independent projection, full construction
history retained.
