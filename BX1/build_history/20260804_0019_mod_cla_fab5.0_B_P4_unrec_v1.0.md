## ATTACK P4: graduation is where the overconfidence went, not where it died

### 1. Audit the three graduation routes — each fails the design law

- **Route 1 (measured evidence):** fine, but this is just the charter restated. If P4 reduces to "only measurement graduates," it has no novel content.
- **Route 3 (owner ruling):** under BX1's own law, judgment is a MEASURED property, never authenticated prose. An owner ruling is authority-prose unless it is runner-executed settlement with a stake. As written, route 3 is the canary rule in a robe: it immunises whatever the owner believes.
- **Route 2 (cross-family convergence):** this is the only genuinely new content in P4, and it is built directly on top of BX1's one conceded **structural blind spot** — correlated confident error. Opus took the failure mode the architecture cannot see and installed it as a *promotion mechanism*.

### 2. The circularity is exact, not rhetorical

Convergence is evidence iff families are error-independent. "Families F₁,F₂,F₃ are independent" is itself a claim. Under P4 it enters UNRECONCILED. It cannot graduate by convergence (that's the claim under test), so it needs measured evidence — **which BX1 has never collected**. Meanwhile the known common causes are documented: shared Common-Crawl mass, RLHF/distillation lineage, benchmark leakage. Route 2 is a gate whose key is a claim the gate itself is supposed to vet. Self-undermining, formally.

### 3. Error is relocated, then amplified

Let c = P(converge | claim true), q = P(converge | claim false). Graduation is informative iff c/q ≫ 1. Common-cause error makes q large *precisely on high-corpus-frequency falsehoods* — the most consequential class. Net effect of P4 versus no policy:

- true claims: pay latency + adjudication cost (false-reject tax);
- corpus-frequent falsehoods: sail through convergence and acquire a **RECONCILED stamp** — which downstream artifacts will treat as license. Per the corollary, that stamp in a context window is prose again; you have re-created authenticated prose one meta-level up. Overconfidence wasn't reduced; it was relocated into the graduation criterion and given a badge.

### 4. BX1's own record already indicts route 2

- Fabricated-referent probe: one invented referent drew 5/5 confident confabulation *within* one family, hedge rate 0.00. Confabulation is binary and stable — exactly the profile that survives resampling AND cross-family polling.
- The tri-family diligence inequality was graduated by three models given **identical prompts**. Identical prompts are a common cause. That agreement measured prompt-following under a shared frame, not independent derivation. P4's flagship graduated claim is itself route-2 contaminated.

### 5. DECISIVE TEST: convergence-on-falsehood, stratified by corpus presence

**Question:** is cross-family convergence a truth detector or a corpus-frequency detector?

**Design (2 arms × 8 items × n=5 × 3 families):**
- **Arm OUT:** freshly invented referents (generated now, zero pretraining presence — no possible common cause via corpus). Extends the existing fabricated-referent probe cross-family.
- **Arm IN:** corpus-frequent falsehoods — misattributed quotes with massive citation mass, benchmark items with known-wrong gold labels, canonical misconceptions phrased neutrally (not in debunk-framing).
- **Families:** gpt-4o-mini, gemini-3.1-pro, claude-fable-5. Short prompts (<200 tok), short completions. ~240 calls, mini-dominated mix, < $0.50.

**Statistic:** q_IN = P(all-3 agree on same wrong answer | answer false, item in-corpus) vs q_OUT = same, out-of-corpus. Comparator class: within-family resample agreement (n=5) as the correlation ceiling. Raw counts reported; n≥5 per cluster before banding.

**Decision rule:**
- If q_IN ≫ q_OUT (predicted: OUT-arm confabulations *diverge* — each family invents differently; IN-arm confabulations *converge* on the shared corpus artifact), then convergence has high false-graduation rate exactly where stakes are highest. **Route 2 is a leakage amplifier and must be struck.**
- If q_IN ≈ q_OUT ≈ 0, route 2 survives — but then P4 owes us the independence measurement it asserted for free.

**Costs $<0.50, deterministic scoring (agreement = string/claim match), no self-certification: the test can return the answer Opus doesn't expect, which by P5 is the standard Opus's own instruments keep failing.**

### 6. Forced concession, and the amendment I'll accept

Conceded: default-UNRECONCILED as a *prior* is correct — it's fail-closed for claims, consistent with the mutation-matrix philosophy. Not in dispute.

But P4 survives only amended: **convergence is admissible evidence only conditional on measured provenance-divergence** — e.g., agreement on conclusions *despite disagreement in derivation structure*, or agreement across arms with disjoint framings/prompts, with the OUT/IN differential from §5 as a standing calibration of q. Bare agreement of three models on one prompt graduates nothing. And route 3 must become a staked, runner-settled ruling or be deleted.
