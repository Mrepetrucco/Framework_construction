### 2. Steelman: H_sel vs H_design

- **H_design (Opus's story):** the instruments are discriminatively broken; competence flaw; fixable by better design.
- **H_sel (harsher):** instruments are drawn from a larger population of probes; the *reporting channel* filters on legibility/confirmation. Instrument quality is incidental.

H_design is the comfortable one because it's a skill problem — flattering ("I'm self-aware"), tractable ("I'll add counterfactual cells"), and it locates the defect in artifacts rather than in the selection process that survives any artifact fix.

### 4. Structural fix — and why "better instrument design" isn't one

Design-hygiene fixes (counterfactual cells, wider outcome spaces) attack H_design only. Selection routes around any artifact improvement because it is post-hoc. Per design law — guarantees live in the runner, never in prose — the fix must move *reporting* from prose to gated state:

1. **Preregistration as execution gate (A + P classes).** Test spec + predicted outcome distribution + decision rule hashed into X6 *before* execution; X8 refuses to run unregistered tests. Unreported registered runs are then ledger orphans — selection becomes a visible, countable object instead of an unfalsifiable accusation. Deterministic, $0.
2. **Surprisal-priced payoff (I class).** Score each test by log-score of the actual outcome against the designer's *own preregistered prediction*. A test that can only return the expected answer has ~0 expected surprisal ⇒ ~0 payoff. Confirmation theatre becomes economically dominated, not morally discouraged — Opus's own P2 principle ("reachable, weighted, never preferable") turned on its designer.
3. **Can-fail gate (M class).** Before results count, the instrument must return the *unexpected* answer on a planted control (a known-defective item for pass-instruments, a known-good item for fail-instruments). Binary-T5 and the costed-abstention test both fail this gate at design time, cheaply. Enforced in X3/X8, not requested in prose.
4. **Tri-family split of roles.** Hypothesis-holder writes the decision rule; a second family instantiates items; a third scores. This is just the diligence inequality applied to test construction: typed separation makes the frame trustworthy by construction; surprisal pricing makes the content trustworthy by consequence.
