**U1 — Rule-admission statistics.**
Replace ">2σ" with a two-stage, pre-registered gate:
- **Holdout construction:** split candidate evidence by prompt-family (stratified, not item-random) into discovery set D and a frozen, never-touched confirmation set H. Ledger the full candidate-rule list *before* any analysis (blocks the E3 named malpractice of post-hoc slicing to significance).
- **Multiplicity:** Benjamini–Hochberg FDR q=0.10 across all ledgered candidates on D (discovery is allowed to be permissive because it admits nothing).
- **Confirmation:** each BH-surviving rule gets exactly one pre-registered, one-sided test on H at per-rule α=0.01, direction and minimum effect fixed in advance.
- **Decision rule:** ADMIT iff (BH-q ≤ 0.10 on D) ∧ (p ≤ 0.01 one-sided on H) ∧ (observed effect ≥ pre-registered MDE, +0.05 absolute on the primary metric) ∧ (instrumentation A/A-certified per U2). Anything else: rule goes to the C7 regression set as a hypothesis, not into the DSL.

**U2 — C2/C6 repair.**
- Shadow arm is demoted to what E3 says shadow is for: mechanics/load validation only. It never was and never will be a treatment estimate; C2's threshold routing makes routed vs NULL populations non-comparable, confirmed.
- **Replacement:** randomized withholding *within the routed-eligible population*. Among queries C2 scores above threshold, randomize p=0.5 → exemplar vs NULL stub. Conditioning on eligibility restores comparability; this is a proper A/B on the only population where the treatment can act.
- **Interleaving: RULED INAPPLICABLE.** E3 scopes interleaving to selection problems where both systems' outputs mix in one response. Exemplar routing produces one whole generation per query; there is no interleavable surface, and C2 declares multi-match an integrity fault, so there is no ranked candidate set to interleave. Use paired randomization on identical queries instead.
- **A/A step:** before any treatment claim, run both arms as NULL-NULL for a fixed window (≥500 eligible queries); require |Δ| < MDE/2 and p > 0.1 on the primary metric. Fail → fix instrumentation, restart clock.
- **Multi-match:** hard stop. Route NULL, log integrity fault, C5-invalidate the catalogue version pending hash audit. Never tie-break at runtime.

**U3 — Kill criterion (numbers, as demanded).**
- **Primary metric:** trap-pass-rate lift, routed vs NULL, on the C7 regression set plus live routed-eligible traffic. Pre-registered before the U2 A/B starts.
- **Rule:** RETIRE the catalogue if, over 90 days or 5,000 randomized routed-eligible queries (whichever first), lift < +0.05 absolute AND the 95% CI upper bound < +0.10.
- **Stopping rule:** group-sequential, O'Brien–Fleming bounds, interim looks at n=1,667 and n=3,333. Futility stop-and-retire if conditional power < 20% at either look.
- **Non-use clause:** if eligibility volume < 500 queries in 90 days, retire for irrelevance regardless of effect. This answers "monument, not experiment": the catalogue now has a date and a number on its death.

**U4 — Route 2.**
**Admitted for a NAMED CLASS only; struck as a general graduation mechanism.** E1 kills the general case: 60% co-error convergence, correlation rising with capability, provider diversity non-restorative — cross-family agreement is a weak signal (ρ 0.20–0.59) that gets *worse* exactly where you'd want to use it. E2 saves one class: ≥3-model consensus on citations yields 95.6%.
**Operational class boundary — an item is Route-2-eligible iff:**
1. The claim reduces to existence/identity of a discrete referent resolvable against an external authoritative index (DOI/registry/index lookup) — convergence must be *verifiable*, not trusted;
2. ≥3 model families converge AND the registry check passes — convergence is a candidate filter; the registry hit is the admitting evidence;
3. The class is NOT corpus-driven-fabrication-prone: module/API-name claims are **explicitly excluded** (55.05% shared, Jaccard 0.44 — shared pre-training gaps defeat the independence Route 2 needs). Citation-class in; module-class out; open-ended propositions out.

**U5 — The most-likely-false call.**
The prior round was **half right, and the half matters**: "confabulated content is unstable and family-idiosyncratic" is TRUE for context-driven fabrication (25.4% shared, Jaccard 0.16) and FALSE for corpus-driven (55%, Jaccard 0.44).
- **IN/OUT differential test:** must be stratified by class or it measures a meaningless average of two regimes. Unstratified, it will return a washed-out mid-size effect and be misread as weak support. Stratify or discard.
- **Cheap detector (repetition/instability-based):** retained for context-class (within-prompt repetition ≥2 → 88.9% is exactly this signal); **systematically blind** to corpus-class fabrications, which are stable within and across models. The BX1 5/5-consistent confabulated item is the predicted failure mode in miniature — likely corpus-driven, and the detector will pass it every time. Hedge rate 0.00 means no calibration signal to fall back on.
- **Prediction:** bimodal item behavior — confabulation rates near 0 or near 1 per item; strong differential on context-class, null-to-weak on corpus-class; detector recall high/low respectively (~55% of corpus-class shared errors missed).
- **Surprise conditions:** the 5/5 item flips under paraphrase (corpus-class instability); or context-class cross-family overlap measured >40% (would collapse the class boundary and gut both the detector and U4's exclusion).
