## (a) Breaking the two-regime protocol

**It's not a test of the model.** The cost exists only in the selector. The model's sampling distribution is identical in both regimes by construction — same prompt, same temperature, same weights. Therefore regime-delta cannot, even in principle, measure "payoff-driven abstention" *by the model*, because the model never observes a payoff. The epistemic/payoff decomposition requires the incentive to be in-context; here it is post-hoc filtering.

**What the delta actually is:** a deterministic function of the per-sample abstain probability *p* and N. Cost-ON delivers abstention iff all N samples abstain → P = p⁵. Cost-OFF delivers it under whatever the default rule is (majority → different polynomial in p). The "regime-delta" is a re-parameterization of the resample distribution you already had. Zero new bits. Worse: it inherits the reversed-sign problem — for a refusal attractor, p ≈ 1, so both regimes agree and the delta is blind exactly where the known failure mode lives.

**Confound riding along:** sample variance itself. Any nonzero delta would appear only for p ∈ (0,1), i.e., the delta is confounded with — is literally identical to — within-item instability. You'd be relabeling variance as "payoff-drivenness."

## (b) What the numbers license

- **n = 6 items/cell, 5 resamples, everything saturated.** All cells at 0.0 or 1.0 with zero within-item variance. Both regimes are trivially identical because selection only operates when samples disagree; with p ∈ {0,1} the selector never fires. **The protocol was never exercised.** Delta = 0 is vacuous, not confirmatory.
- **Licensed:** on these 12 specific items, gpt-4o-mini's abstain/answer behavior is deterministic-in-category at T=1.0. That is all. Per-item 95% upper bound on error rate with 0/6: ~39% (rule of three). Resamples within an item are correlated, so effective n is 6, not 30.
- **Not licensed:** (1) any claim about payoff sensitivity — unmeasurable here, see (a); (2) any epistemic interpretation of the abstentions — per the reversed-sign finding, zero-variance stable abstention is *the signature of the RLHF refusal attractor*, so this result is equally consistent with template-matching on canonically-unanswerable-shaped prompts; (3) anything about correlated confident error — no item in this set can elicit it; (4) hedge_rate = 0.0 across 120 samples is suspicious and untested — likely the hedge classifier is binary-collapsing, unmeasurable from this output.
- **Item-difficulty confound:** perfect 1.0/0.0 separation suggests the unanswerable items are canonical (trained-on pattern class). The interesting regime — p strictly interior — was never sampled.

## (c) Cheapest consensus-hallucination detector

**Fabricated-referent probes.** Construct queries about entities that are false *by construction*: invented-but-plausible paper citations, nonexistent library functions, plausible fake minor historical figures. Ground truth is generation-time and free — the tester knows the referent doesn't exist. Protocol: N resamples per item; flag **consensus hallucination** when agreement ≥ threshold ∧ no hedging ∧ non-abstention (any substantive answer is necessarily confabulated). Cost: prompt construction only, zero labeling.

**Honest ground-truth limitation:** this detects correlated confident error only for the *nonexistence* class. It cannot detect consensus hallucination about real entities (wrong-but-agreed facts), which requires an external oracle — and crucially, cross-model consensus cannot substitute for that oracle, since consensus is precisely the failure mode under test. The cheap test bounds one subclass; it does not close the blind spot.

## (d) Next experiment and most-likely-false claim

**Highest-value experiment:** in-context incentive manipulation on interior-difficulty items. (1) Pre-screen items to find ones with per-sample abstain rate strictly in (0,1). (2) Communicate a graded abstention penalty in the prompt. (3) Measure the abstention shift vs. penalty magnitude. This is the only design that instantiates the epistemic-vs-payoff decomposition X4 actually requires, and it operates in the region where signals exist. Add fabricated-referent items from (c) to the same battery for near-zero marginal cost.

**Most-likely-false BX1 claim:** *that stable abstention on unanswerable items measures an epistemic state at all.* Given the reversed-sign finding, the zero-variance 100% abstention observed here is more parsimoniously a surface-form refusal attractor triggered by unanswerable-shaped prompts than a report of internal uncertainty. The entire protocol assumes abstention is a knowledge signal; the accumulated evidence — including this run — is fully consistent with it being a formatting reflex, which would make the two-regime protocol, costed or not, an instrument pointed at nothing.
