# 20260803_2327_mod_all_fuzz-band-qualifiers_v0.1
Owner correction accepted: quarantined out-of-band output is NOT merely waste — if we collect it, it has weight,
and it may point intention along a correct path ADJACENT or ORTHOGONAL to initial scope. So it needs QUALIFIERS,
not a flat "never counted as success".

Qualifier set on every quarantined item:
| qualifier | meaning | disposition |
|---|---|---|
| `malformed` | failed shape, no semantic content added | discard after logging; counts toward m5 burden |
| `in-scope-shape-miss` | right intent, wrong envelope | RESAMPLE; validator tolerance may be too tight |
| `adjacent-scope` | answers a neighbouring question the request implied but did not state | SURFACE to owner as an unresolved item; never auto-delivered |
| `orthogonal-insight` | out-of-scope but materially informative about the task or the SPEC | ROUTE to the Lambda (X7) spec-fidelity channel — this is a specification signal |
| `spec-defect-evidence` | recurring pattern implying `valid` predicate is wrong | ESCALATE; triggers X3 tolerance review |
Anti-gaming invariant (unchanged): no qualifier makes quarantine score >= a valid delivery. Reachable, weighted,
never preferable. The weight is INFORMATIONAL (routes to owner/spec), never REWARD (never enters the selection payoff).
That split is what keeps it non-strategic while still counting.
