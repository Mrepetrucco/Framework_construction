# 20260804_1141_mod_all_uncertainty-raise-rule_v1.0
OWNER RULING: fabrications sit ON THE BOUNDARY OF UNCERTAINTY. The boundary is raised to the user — it is not
resolved by guessing, and it is not left to a mis-match.

## THE RULE
When the frame is uncertain — no confident match, a multi-match correlation group, an unresolvable referent, or a
claim that would require inventing context — the system RAISES to the user. It does not:
- pick a frame and proceed (mis-match), nor
- probe/stress the context to see what comes back (that probing is itself what produces fabricated referents).
Ideally the raise carries a LIVE FACT SOURCE addition: an external retrieval attached to the question, so the
user is answering with evidence in hand rather than being asked to adjudicate blind.

## WHY NOT "TEST THE CONTEXT"
Fabrication is PROMPT-INDUCED [EXTERNAL: no model spontaneously fabricates citations unprompted]. A test designed
to see whether the context holds is a prompt, and a prompt aimed at an uncertain referent is exactly the
condition that manufactures the fabricated referent. The concern to test the context CREATES the artefact it
was meant to detect. Raise instead.

## QUESTION-SCOPE DISCIPLINE (owner ruling, standing)
A question must NOT cross-translate or over-extend meaning beyond the context it sits at. The only permitted
move outward is ASKING A FURTHER QUESTION for validation. Concretely: a raise reports the frame as found, in the
vocabulary of that frame, and adds no interpretation, no generalisation to neighbouring frames, and no inferred
intent. If a wider reading is needed, that is a SECOND question, asked as such.

## CROSS-FAMILY CONVERGENCE — SCOPE CORRECTED
Cross-family convergence IS real and IS good for VERIFYING MACHINERY (does the mechanism behave the same way
across independent implementations). It is NOT thereby licensed for CONTEXT HANDLING — deciding what the owner
meant, or which frame is right, is not a thing convergence can settle. Machinery: convergence admissible.
Context: raise to the owner.
