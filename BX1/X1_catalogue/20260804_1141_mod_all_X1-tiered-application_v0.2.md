OWNER RULING: **there is no catalogue retirement.** All of the owner's context is always valid FOR THE OWNER.
A marginal-lift threshold is therefore the wrong instrument — it would retire context that remains valid simply
because a population-level average did not move. The prior U3 numeric kill rule is WITHDRAWN.

## WHAT REPLACES IT: TIERED APPLICATION
Tiers govern HOW STRONGLY an exemplar is applied, never WHETHER it is retained. Nothing is ever deleted.
| tier | condition | application |
|---|---|---|
| T-DIRECT | direct hit: the entry's origin context matches the current frame | applied in full; a direct hit is always honoured and is never diluted by tier statistics |
| T-ADJACENT | same knowledge-graph origin, different frame | applied as supporting shape only |
| T-LATENT | retained, no current frame match | not applied this call; remains fully retrievable and re-tierable |
Movement between tiers is reversible in both directions and carries no stigma. A T-LATENT entry is dormant, not
demoted; a single future direct hit restores T-DIRECT immediately.

## ALIGNMENT WITH KNOWLEDGE-GRAPH ARTIFACT ORIGINS
Every entry keeps a pointer to its originating artifact/node. Tier is computed against that ORIGIN, so tiering
follows the existing knowledge-graph structure rather than inventing a parallel hierarchy. This is what makes
"always valid" and "proportionate application" compatible: validity is a property of the entry (permanent),
tier is a property of the current frame (transient).

## WHAT MEASUREMENT IS STILL FOR
Measurement now sizes the APPLICATION, never the EXISTENCE. A near-zero measured lift means "apply as supporting
shape" (T-ADJACENT), not "retire". The non-use clause is withdrawn: low volume means low tier, not deletion.
